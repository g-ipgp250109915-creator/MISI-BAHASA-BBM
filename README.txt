MISI BAHASA — BBM DIGITAL INTERAKTIF (PWA)

Kandungan:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icons/icon-192.png
- icons/icon-512.png

CARA BUKA:
1. Extract folder.
2. Untuk ujian biasa, double-click index.html.
3. Untuk fungsi INSTALL sebagai aplikasi (PWA), aplikasi mesti dibuka melalui HTTPS atau localhost.
4. Selepas dihoskan di GitHub Pages/hosting HTTPS, buka pautan menggunakan Chrome/Edge.
5. Pilih Install App / Add to Home Screen.

Nota:
- PWA tidak boleh dipasang sepenuhnya daripada file:// sahaja kerana browser memerlukan secure context untuk manifest/service worker.
